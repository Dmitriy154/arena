# Arena

Тактическая арена на Phaser 3 + TypeScript + Vite: отряды двух наций, выделение,
приказы на движение, расталкивание с учётом массы, туман войны и местность.

## Запуск

Windows: двойной клик по `start-game.cmd` в папке проекта. Он при необходимости
установит зависимости, поднимет dev-сервер и откроет игру в браузере; закрытие окна
консоли останавливает сервер.

Вручную:

```bash
npm install
npm run dev
```

Сборка и проверка типов:

```bash
npm run typecheck
npm run build
```

## Управление

| Действие | Клавиша / мышь |
| --- | --- |
| Выбрать отряд | ЛКМ |
| Добавить отряд к выделению | Shift + ЛКМ |
| Выделить рамкой несколько отрядов | ЛКМ + перетаскивание |
| Приказ на движение | ПКМ |
| Снять выделение | Esc или ЛКМ по пустой земле |
| Выбрать все свои отряды | Ctrl + A |
| Зум | Колесо мыши |
| Камера | WASD или ПКМ / СКМ + перетаскивание |
| Вернуться в меню | M |

Вражеские отряды не выделяются: клик по ним снимает выделение. Короткий клик ПКМ
отдаёт приказ, ПКМ с перетаскиванием двигает камеру — приказ в этом случае не уходит.

## Местность

| Тип | Проходимость | Скорость | Обзор |
| --- | --- | --- | --- |
| Лес | вся пехота; конница не входит | ×0.4 | в чаще обзор падает до 35%, враг внутри виден с 110 px, лес перекрывает луч |
| Вода | никто | — | — |

Обход препятствий считает A*: отряд обходит озеро или лес, а клик по воде приводит его
на ближайший берег. Место в строю, попавшее в воду или в лес для конницы, переносится
на ближайшую проходимую точку, чтобы отряд не вставал на краю.

## Туман войны

- Вокруг каждого своего отряда виден круг радиусом 440 px мира; в чаще леса он
  сжимается до 154 px и восстанавливается у кромки.
- Лес перекрывает обзор: враг за чащей по лучу не отображается.
- Неразведанная карта — сплошная тьма; разведанная, но не просматриваемая —
  затемнена. Разведанные участки запоминаются.
- Враги вне обзора не отображаются, счётчик в HUD показывает только видимых.
- Нужен WebGL (обычный браузерный рендер).

## Нации

| Нация | Цвет юнитов | Управление |
| --- | --- | --- |
| Империя | синий `0x4a86e8` | игрок |
| Орда | красный `0xc0392b` | враг, стоит на месте |

Цвет нации — заливка юнита. Цвет типа отряда — тонкая полоса сверху, чтобы типы
не сливались внутри одной нации.

## Типы отрядов

| Код | Тип | HP | Скорость | Мораль | Масса |
| --- | --- | --- | --- | --- | --- |
| ЛП | Легкая пехота | 90 | 215 | 70 | 1.0 |
| ТП | Тяжелая пехота | 140 | 150 | 85 | 1.6 |
| КП | Копейщики | 100 | 175 | 75 | 1.2 |
| СТ | Стрелки | 70 | 190 | 60 | 0.9 |
| ЛК | Легкая конница | 85 | 320 | 65 | 1.1 |
| ТК | Тяжелая конница | 160 | 265 | 80 | 2.0 |

Скорость — пиксели мира в секунду, мораль — 0..100, масса — 1.0 за эталон пехоты.

## Стартовая расстановка

Мир 3840×2160. Армии стоят в левой и правой четвертях, между ними ~1900 px и
центральная чаща.

- Империя (960, 1080): линия пехоты ЛП, КП, ТП, за центром стрелки, на флангах
  конница (ЛК слева, ТК справа).
- Орда (2880, 1080): КП, ТП, КП в линии, стрелки позади. Стоят на месте
  и не действуют.

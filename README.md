# Arena

Простая тактическая арена на Phaser 3 + TypeScript + Vite.

## Запуск

Windows: двойной клик по `start-game.cmd` в папке проекта. Он при необходимости
установит зависимости, поднимет dev-сервер и откроет игру в браузере; закрытие окна
консоли останавливает сервер.

Вручную:

```bash
npm install
npm run dev
```

Сборка и проверка типов:

```bash
npm run typecheck
npm run build
```

## Управление

| Действие | Клавиша / мышь |
| --- | --- |
| Выбрать отряд | ЛКМ |
| Добавить отряд к выделению | Shift + ЛКМ |
| Выделить рамкой несколько отрядов | ЛКМ + перетаскивание |
| Приказ на движение | ПКМ |
| Снять выделение | Esc или ЛКМ по пустой земле |
| Выбрать все отряды | Ctrl + A |
| Зум | Колесо мыши |
| Камера | WASD / стрелки или СКМ + перетаскивание |
| Вернуться в меню | M |

## Типы отрядов

| Обозначение | Тип | Цвет |
| --- | --- | --- |
| ЛП | Легкая пехота | синий |
| ТП | Тяжелая пехота | фиолетовый |
| КП | Копейщики | оранжевый |
| СТ | Стрелки | зеленый |
| ЛК | Легкая конница | бирюзовый |
| ТК | Тяжелая конница | красный |

В стартовой группе четыре отряда: ЛП, ТП, КП и СТ. Остальные типы описаны в
`src/game/types.ts` и готовы для добавления на поле.
